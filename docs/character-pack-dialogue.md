# 透明角色与消息气泡

角色图片建议使用带 alpha 通道的 PNG 或 WebP。背景应透明，浅色衣服和眼睛仍应不透明；不要把棋盘格画进图片。保留原图，将文字作为 manifest 中的台词保存，人物图本身不带字幕。

目录中的 `half_body.webp` 是默认半身图，`thinking.webp` 和 `working.webp` 是独立状态图。没有某个状态图时，显示默认图，不要求复制同一张图片凑齐状态。

```json
{
  "id": "my-companion",
  "name": "我的伙伴",
  "dialogue": {
    "idle": ["我在这里。"],
    "thinking": ["让我想一想。"],
    "working": ["专心做眼前这件事。"]
  }
}
```

支持 `idle`、`happy`、`thinking`、`working`、`error`、`sleepy` 六种状态。每种最多 12 句，每句最多 160 字符；内容仅作为纯文本显示。未知状态或没有台词时回退到 idle，再回退到内置台词。

打开角色详情可预览状态和台词。点击陪伴角色弹出消息，约 5 秒后收起；开启自动状态与欢迎语后，专注、完成等真实事件也会触发气泡。轻晃和切换过渡遵循动画开关与系统减少动态设置。关闭自动状态时，点击仍可显示待机台词。

在桌面版，将包放入用户数据目录下的 `characters/角色名/`，重新进入设置会扫描更新。重新导入同一角色会更新图片和台词，即使新旧图片字节数相同也会刷新缓存。图片与台词保存在本机，不上传。

本仓库不包含个人搜集的第三方角色图片、个人设置或业务数据。透明角色包由用户本地管理；代码功能适用于任何兼容角色包。
