# UI_ACCEPTANCE: 习惯打卡数值输入交互优化

## 日期
2026-07-04

## 验收标准

### 1. 原生 spinner 已隐藏
- [ ] 数字输入框不显示浏览器原生上下箭头
- [ ] 使用 `appearance: textfield` 和 `-webkit-inner-spin-button` 样式

### 2. 数字滚轮视觉效果
- [ ] 当前选中值颜色最深、字体最大或最粗
- [ ] 相邻值（上下或左右）颜色逐级变浅
- [ ] 当前值居中突出显示
- [ ] 过渡动画 ≤ 200ms

### 3. 操作方式
- [ ] 鼠标滚轮：hover 时向上增加、向下减少，防止页面滚动
- [ ] 点击相邻数字：可点击并切换当前值
- [ ] 键盘：ArrowUp/ArrowRight 增加，ArrowDown/ArrowLeft 减少
- [ ] 直接输入：点击当前值可输入数字，Enter 确认，Esc 取消
- [ ] 触控拖动：手机端可滑动调整

### 4. 保存交互
- [ ] 保存按钮不突然蹦出导致布局重排
- [ ] 操作区固定宽度，编辑/保存不改变卡片布局
- [ ] 自动保存状态有明确反馈（保存中/已保存/保存失败）
- [ ] 数据不会静默丢失

### 5. 快捷按钮
- [ ] +5/+10/+15/+30 按钮保留但增大
- [ ] 点击区域足够大（≥ 32px 高度）
- [ ] 按钮间距合理
- [ ] 不抢占数字滚轮的主视觉

### 6. 不同计量方式
- [ ] boolean → 勾选切换（不变）
- [ ] count → +/- 1 + 滚轮 + 输入
- [ ] minutes → 快捷按钮 + 滚轮 + 输入
- [ ] hours → +0.5/+1/+2 + 滚轮 + 输入
- [ ] numeric → +/- 步进 + 滚轮 + 输入 + 单位

### 7. 手机端
- [ ] 控件不挤在一行导致过小
- [ ] 触控区域 ≥ 44px
- [ ] 快捷按钮可点击
- [ ] 无横向溢出
- [ ] 不遮挡底部导航

### 8. 深色模式
- [ ] 当前值突出
- [ ] 相邻值可读但弱化
- [ ] 边框不过亮
- [ ] 输入态焦点清晰
- [ ] 错误状态清晰

### 9. 编辑和删除
- [ ] 今日记录可修改
- [ ] 历史记录可修改
- [ ] 记录可删除（有确认）
- [ ] 删除后显示 0 / 未打卡
- [ ] 统计刷新

### 10. 质量闸门
- [ ] TypeScript 0 errors
- [ ] ESLint 0 errors
- [ ] Vitest 全部通过
- [ ] Playwright E2E 全部通过
- [ ] Production build 通过
