## Playwright E2E 测试

### 场景一：分钟型习惯滚轮调整
- 打开首页或习惯页
- 找到分钟型习惯
- hover 数字滚轮
- 鼠标滚轮向上 → 验证增加 5 分钟
- 鼠标滚轮向下 → 验证减少 5 分钟
- 验证页面没有整体滚动异常

### 场景二：点击相邻数字
- 打开分钟型习惯
- 验证当前值最突出（颜色最深/字体最大）
- 点击相邻较大的数字 → 验证当前值更新
- 点击相邻较小的数字 → 验证当前值更新

### 场景三：直接输入
- 点击当前数字 → 进入输入模式
- 输入 45 → Enter 保存
- 验证显示 45 分钟
- 刷新页面 → 验证仍为 45 分钟

### 场景四：保存按钮不跳动
- 记录习惯卡片初始位置和尺寸
- 操作数值滚轮
- 验证卡片布局无明显横向跳动
- 验证操作区没有突然出现/消失

### 场景五：手机端 (390×844)
- 打开习惯区域
- 数字滚轮可见且可操作
- 快捷按钮可点击（足够大）
- 可直接输入
- 编辑和删除可用
- 无横向溢出

### 场景六：深色模式
- 切换深色模式
- 当前数字最突出
- 相邻数字可读但弱化
- 无对比度问题
