# SPEC: 习惯打卡数值输入交互优化

## 日期
2026-07-04

## 当前问题

1. **快捷按钮过小**：`+5`、`+10`、`+15`、`+30` 按钮 `h-6 text-[10px] px-1.5`，在桌面勉强能用，手机端极易误触
2. **原生数字输入箭头**：`<Input type="number">` 显示浏览器原生上下箭头（spinner），样式不佳且不好点击
3. **保存按钮布局跳动**：输入值后"保存"按钮条件渲染出现，挤开周边元素，导致卡片布局重排
4. **缺少滚轮/触控交互**：不能通过鼠标滚轮或触控滑动调整数值，只能点击小按钮
5. **连续操作体验差**：要增加 30 分钟需要点击 +30 按钮，或手动输入数字后点击保存

## 目标交互：数字滚轮

### 核心设计
- 当前选中值：颜色最深、字体最大/最粗、最突出
- 相邻值（上下或左右）：颜色逐级变浅、字体变小
- 可滚轮调整：鼠标滚轮向上增加、向下减少，防止页面滚动
- 可点击相邻数字调整
- 可键盘输入：聚焦后 ArrowUp/ArrowRight 增加，ArrowDown/ArrowLeft 减少
- 可触控拖动（手机端）：滑动改变值
- 可直接输入：点击当前值进入输入模式

### 不同计量方式的步进

| 计量方式 | 步进 | 快捷按钮 | 单位 |
|---------|------|---------|------|
| count | 1 | +1 | 次 |
| minutes | 5 | +5, +10, +15, +30 | 分钟 |
| hours | 0.5 | +0.5, +1, +2 | 小时 |
| numeric | 根据 target 自动 | +/- 步进 | 自定义 |
| boolean | N/A | 勾选切换 | N/A |

### 边界处理
- 最小值 0，最大值合理设置
- 当前值为 0 时正常显示
- 支持小数（hours 的 0.5）
- 空值/非法输入处理
- 快速连续滚动/触控连续滑动防抖
- 保存失败/网络延迟处理

## 保存策略

选择 **方案 B：固定操作区**。

- 每个习惯卡片右侧始终预留固定宽度的操作区
- 未编辑时显示编辑图标 + 删除图标
- 编辑时同一位置切换为保存 + 取消
- 因为空间已预留，不会出现布局跳动

保留 `debounce` 自动保存作为未来优化方向（方案 A），但如果当前实现复杂则使用固定操作区。

**选择原因**：
1. 符合现有卡片布局，改动最小
2. 固定操作区不参与条件渲染，从根源避免布局跳动
3. 用户始终知道在哪里操作
4. 与决策 17（系统性减少弹窗）一致

## 编辑和删除

- 今日记录可修改（行内编辑 + Dialog 编辑）
- 历史记录可修改（Dialog 编辑）
- 记录可删除（需确认）
- 删除后卡片显示 0/未打卡
- 统计刷新、热力图刷新

## 桌面和手机差异

### 桌面端
- 数字滚轮 + 快捷按钮 + 操作区横向排列
- 鼠标滚轮可用
- hover 时显示相邻数字

### 手机端
- 横向排列但控件间距更大
- 触控区域不小于 44px
- 数字滚轮支持触控滑动
- 快捷按钮保留但增大点击区域
